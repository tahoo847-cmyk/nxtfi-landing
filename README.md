# NxtFi cinematic hero

Visual and animation test: a pinned 3D hero and Section 02, The Payment Challenge.

```bash
npm install
npm run dev
```

Open http://localhost:3100. For a production run, use `npm run build` then `npm run start`.

- Assets and credits: `asset-manifest.md`
- Scroll choreography: `docs/animation-map.md`, values in `components/hero/choreography.ts`
- Test results: `docs/qa-report.md`, frames in `docs/screenshots/`
